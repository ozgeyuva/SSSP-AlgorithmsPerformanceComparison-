# SSSP Algorithms Performance Comparison

This project compares the performance of two Single-Source Shortest Path (SSSP) algorithms:

- Dijkstra's Algorithm
- Bellman-Ford Algorithm

## Objective

To analyze and compare the theoretical and practical performance of SSSP algorithms based on:

- Runtime
- Memory usage
- Scalability

## Dataset

- Synthetic graphs (small, medium, large)
- DIMACS Road Network dataset (New York subset)

## Technologies

- Java
- OOP
- ArrayList
- PriorityQueue

## Results

- Dijkstra performs efficiently on large graphs
- Bellman-Ford becomes impractical for large datasets
- DIMACS dataset confirms real-world scalability differences

## How to Run

1. Open the project in IntelliJ IDEA
2. Run `Main.java`
